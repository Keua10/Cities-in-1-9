# Cities in 1-9 — 보행자 시스템 개편 완료

## 수정 파일
- `src/main.ts`
- `src/sim/pedestrianSystemPatch.ts` (신규)

## 핵심 변경
- 기존 `PedestrianPool`의 카메라 초점 기반 24개 후보/3명 왕복 표시를 런타임 패치로 교체.
- 카메라 이동 시 보행자를 전부 지우지 않고, 5x5 청크 범위에서 계속 시뮬레이션하며 충분히 멀어진 보행자만 정리.
- 보행자 수는 지역의 주거/상업/공업 건물 정원, 실제 도시 인구/입주 수준, 시간대에 따라 달라짐.
- 주거→상업 이동을 가장 높은 비중으로 설정하고 주거→주거는 소수만 생성.
- 짧은 이동(4~17타일)과 긴 이동(18~58타일)을 혼합하며 긴 이동 비중은 55%.
- 목적지 도착 후 짧게 머물다 제거. 같은 경로를 즉시 왕복하지 않음.
- 보행 경로에서 도로 내부 횡단은 신호가 있는 교차로 주변에서만 허용.
- 횡단 시 별도 보행자 신호 오브젝트를 추가하지 않고 기존 차량 신호 상태를 사용.
- 건너는 차량축이 빨간불이고 교차로 주변의 움직이는 차량이 충분히 멀 때만 횡단 시작.
- 횡단을 시작한 뒤에는 신호가 바뀌더라도 도로 한가운데서 멈추지 않고 건너편까지 진행.
- 빨간불을 받고 정지선 뒤에 멈춘 차량은 보행 횡단을 불필요하게 차단하지 않음.

## 저장/시뮬레이션 영향
- 저장 스키마 변경 없음.
- 실제 인구, 입주율, 차량 통행 발생량 변경 없음.
- 화면에 표현되는 보행자 파생 레이어만 변경.
- 맵 초기화 필요 없음.

## 검사
- 프로젝트와 동일한 TypeScript 옵션(`strict`, `noUnusedLocals`, `noUnusedParameters`, `isolatedModules`) 기준 신규 모듈 타입 검사 오류 0.
- 합성 도로 검사:
  - 신호 교차로가 존재할 때 해당 위치로 우회 후 횡단.
  - 신호 교차로가 없으면 임의 도로 횡단 경로 생성 안 함.
  - 횡단 대상 차량축 빨간불: 횡단 가능.
  - 초록불: 대기.
  - 빨간불 정지선 뒤 정지 차량: 횡단 허용.
  - 움직이는 차량이 횡단부 근처에 있음: 대기.


## 추가 보완: 줌 렌더링 / 보행자 우선 횡단

- 보행자 렌더링 최소 배율을 0.65로 설정. 0.65 미만에서는 Graphics를 비우고 그리지 않지만 보행 시뮬레이션은 계속 진행한다.
- 횡단을 시작한 보행자가 교차로에 남아 있는 동안 해당 교차로 ID를 activeCrossings로 유지한다.
- TrafficSim.holdProgress를 인스턴스 단위로 감싸, activeCrossings에 해당하는 교차로로 진입하려는 차량은 신호가 초록으로 바뀌어도 정지선에서 기다리게 한다.
- 이미 정지선을 넘어 교차로 내부에 들어간 차량은 갑자기 정지시키지 않는다.
- 기존 vehicleMotionPatch가 holdProgress를 매 프레임 호출하므로 차량 감속 효과도 그대로 적용된다.
