# STEP 3.2 FIX6 — traffic polish / collision / signals

## 이번 수정

- 차량 발생을 즉시 스폰 방식에서 결정론적 headway 대기열 방식으로 변경.
  - `MAX_SPAWNS_PER_SEC = 90`은 STEP 3.2 명세의 비상 상한으로 유지.
  - 정상 발생은 55~140ms 간격으로 분산되어 한 프레임/한 순간에 차량이 쏟아지는 현상을 줄임.
  - 막힌 진입로 하나 때문에 다른 진입로까지 막히지 않도록 준비 큐를 제한적으로 순회.
- 우측통행 렌더 좌표 수정.
  - 기존 화면 좌표의 왼쪽 법선 `(-dy,+dx)`를 오른쪽 법선 `(+dy,-dx)`로 교정.
  - 코너에서 현재 차선 오프셋→다음 차선 오프셋을 smoothstep 보간하여 회전 순간 횡이동을 완화.
- 차간거리/겹침 방지 강화.
  - 회전 중 차량을 현재 진행방향과 진입방향 양쪽 lane occupancy에 등록.
  - 제동거리 기반 안전속도 제한 및 프레임당 최대 진행거리 clamp 추가.
  - 감속 상수를 48 tiles/s²로 높여 8 tiles/s 차량이 정지선 전에 실제로 멈출 수 있게 조정.
- 교차로 reservation 추가.
  - 3방향 이상 자동 신호 교차로는 동시에 한 차량만 교차로 내부를 점유.
  - 빨간불/황색 및 점유 중 교차로 앞에서 `INTERSECTION_STOP_T=0.94` 정지.
  - 같은 프레임 동시 진입도 reservation으로 차단.
- 신호등 시각 확인용 임시 표시 추가.
  - 연결 3개 이상 교차로에 자동 표시.
  - 차량 판정과 동일한 signal clock을 사용.
  - 정식 신호등 스프라이트 전 임시 2축 적/녹 표시.
- 혼잡 재탐색 순간이동 완화.
  - 교차로 중심 부근에서만 재탐색 적용.
  - 요청 중 차량이 이미 진행했으면 새 경로를 폐기하여 `tileT=0` 순간이동 제거.
- `CongestionMap.rebuildEstimate()` 시작 시 이전 estimate 배열 초기화.
  - 도로/직장 변경 후 유령 혼잡이 남는 문제 방지.
- L3 장보기 45타일 경계 수정.
  - 거리 BFS는 `max(commuteRange, shopRange)`까지 계산.
  - 직장 배정은 별도로 commuteRange 제한을 다시 적용.

## 그대로 둔 것

- `MAX_ACTIVE_VEHICLES = 1000`
- `MAX_SPAWNS_PER_SEC = 90`
- 신호 주기 16초: NS 7초 + 황 1초 + EW 7초 + 황 1초
- fallback 차량 atlas의 방향별 색 변화. 정식 `public/sprites/vehicles.png` 교체 시 사라질 임시 표현이므로 이번에는 수정하지 않음.

## WORK에서 우선 확인할 것

1. `npm ci` 후 `npm run build` TypeScript/Vite 전체 빌드.
2. 테스트 도시에서 08:30/09:00 러시 때 차량이 한 번에 폭발하지 않고 연속적으로 흩어져 나오는지.
3. 네 진행방향 모두 실제 화면에서 오른쪽 차선을 쓰는지.
4. 직선 추종, 코너, T자/십자 교차로에서 차량이 서로 겹치지 않는지.
5. 빨간불/황색에서 정지선을 넘지 않고, 초록불에서도 교차로 안에 차가 있으면 기다리는지.
6. 3방향 이상 교차로에만 신호 표시가 자동 생성되고 차량 판정과 색이 일치하는지.
7. 회전 시 차량이 옆으로 순간이동하지 않는지.
8. 혼잡 우회가 일어나도 차량이 뒤로 튀거나 순간이동하지 않는지.
9. 우회로 추가/도로 변경 뒤 예전 혼잡 추정치가 남지 않는지.
10. 미니맵/테스트 도시/FIX4 daytime 출퇴근이 회귀하지 않았는지.
