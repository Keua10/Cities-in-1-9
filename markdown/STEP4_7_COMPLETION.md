# STEP 4.7 — 외곽 지형 비율 조정

기준: main `c8661f8` (4.6 및 광역교통 확장 반영). 기본 도시 바깥의 지형만 조정했다.

- 기존 좌표 기반 연속 노이즈와 WORLD_SEED를 유지하고, 외곽의 해수면·고도 곡선만 재매핑했다. 타일을 무작위로 흩뿌리거나 청크마다 비율을 강제로 맞추지 않는다. 수역은 기존 노이즈의 낮은 지대를 따라 형성되며, 유량 기반 하천 생성은 아니다.
- 표본 기준: 좌표 -2048~2047 범위를 8타일 간격으로 측정하고 원점 기본 도시를 제외한 261,888점. 평지는 물이 아니면서 고도 5 미만, 산은 고도 5 이상, 수역은 깊은/얕은 물이다. 평지 분류에는 낮은 언덕도 포함한다.
- 이전 평지/산/수역은 **59.74% / 12.08% / 28.18%**, 새 외곽 생성값은 **60.02% / 29.99% / 9.99%**다. 넓은 지역의 목표 비율이며 개별 청크마다 같지는 않다.
- 기본 도시 2×2 청크와 도시 번호별 시작 위치를 정하는 기존 지형 함수는 그대로 유지한다. 기본 도시와 보존 청크 바깥에는 32타일 전이 구간을 두어 고도를 이어준다. 전이 구간은 위 비율 측정의 대상인 순수 외곽과 다를 수 있다.
- 기존 저장을 처음 열 때 기존 개척 목록과 저장된 청크 목록을 `macro.legacyTerrainChunks`에 기록한다. 이 목록의 땅은 기존 지형으로 유지하며 새로 개척하는 외곽은 새 규칙을 따른다. 빈 배열은 이전 보정이 완료되었다는 뜻이다. 재접속 시 목록을 늘리지 않는다. 맵 초기화에서도 이 보존 목록은 유지한다.
- 화면에 올라온 지형과 화면 밖 `sampleHeight`가 같은 생성 규칙을 사용한다. 사용자가 수정한 지형·고도 오버레이가 최종적으로 우선한다.

간단한 기능 검사에서 도시 0·1·7의 기본 지형/고도 완전 일치, 기존 외곽 청크 보존, 청크 언로드 후 동일 재생성, 직접 고도 수정 보존, 수역 고도 0을 확인했다. 실제 서버 저장 왕복이나 전체 지형 시각 검수는 하지 않았다.
