# 터치 입력 패치

## 목적

시설 도구를 선택한 상태에서도 한 손가락 드래그로 지도를 이동할 수 있게 한다.
기존 시설 설치, 도로/구역/철거/배관/전선 드래그 설치, 마우스 입력, 두 손가락 핀치 기능은 유지한다.

## 원인

기존 `src/core/input.ts`는 `isPainting()`이 참이면 `pointerdown` 순간 바로 칠하기 상태로 들어간다.
`Tools.isPainting()`은 선택 도구를 제외한 모든 도구에서 참을 반환했기 때문에, 한 번만 배치하는 시설 도구도 한 손가락 드래그를 카메라 이동이 아니라 설치 입력으로 가로챘다.

## 변경 사항

- `Tools.isPainting()`이 세 가지 상태를 표현하도록 확장했다.
  - `false`: 선택 도구
  - `true`: 기존 연속 드래그 칠하기 도구
  - `'tap'`: 시설처럼 한 번만 놓는 도구
- 시설 도구는 터치 `pointerdown` 시 즉시 설치하지 않는다.
- 손가락 이동이 18px 이내에서 끝나면 누르고 있던 시간과 관계없이 기존처럼 처음 누른 타일에 시설을 1회 설치한다.
- 18px를 넘겨 움직이면 시설 설치 후보를 취소하고 카메라 이동으로 전환한다.
- 두 손가락 제스처로 바뀌면 설치 후보를 취소하고 기존 핀치/이동만 수행한다.
- 마우스 시설 설치는 기존처럼 `pointerdown`에서 즉시 설치한다.
- 도로, 구역, 철거, 상하수도관, 전선 등 기존 연속 드래그 도구는 동작을 변경하지 않았다.

## 적용 파일

- `src/core/input.ts`
- `src/ui/tools.ts`

## 적용 방법

ZIP을 저장소 루트에 풀어 같은 경로의 파일을 덮어쓴다.
