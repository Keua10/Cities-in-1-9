# 터치·마우스 시설 배치 중 화면 이동 패치

## 목적

시설 도구를 선택한 상태에서도 모바일과 PC 모두 드래그로 지도를 이동할 수 있게 한다.
시설 설치 기능 자체와 도로/구역/철거/배관/전선의 기존 드래그 설치, 선택 도구의 카메라 이동, 두 손가락 핀치 기능은 유지한다.

## 원인

기존 입력 구조는 시설 도구도 칠하기 도구로 취급한다. 이전 모바일 패치에서는 터치만 `tap` 방식으로 지연 판정했지만, 마우스는 기존처럼 `pointerdown` 즉시 `onPaintStart()`를 실행하도록 남아 있었다. 따라서 PC에서 시설을 든 상태에서는 마우스 버튼을 누르는 즉시 시설 설치 입력이 시작되어 카메라 드래그로 전환할 수 없었다.

## 변경 사항

- `tap` 설치 도구의 지연 판정을 터치뿐 아니라 마우스에도 적용한다.
- 시설 선택 상태에서 마우스 왼쪽 버튼을 누른 뒤 이동이 18px 이내에서 끝나면 처음 누른 타일에 시설을 1회 설치한다.
- 18px를 넘겨 드래그하면 시설 설치 후보를 취소하고 카메라 이동으로 전환한다.
- 모바일도 이전 패치와 동일하게 18px 이내 탭은 설치, 그 이상 드래그는 카메라 이동이다.
- 시설을 누른 채 오래 유지하더라도 18px를 넘지 않았다면 버튼을 뗄 때 1회 설치한다.
- 선택 도구의 마우스 드래그는 기존처럼 데드존 없이 즉시 카메라 이동한다.
- 도로, 구역, 철거, 상하수도관, 전선 등 연속 칠하기 도구는 기존처럼 드래그 설치한다.
- 두 손가락 핀치/이동과 마우스 휠 줌 동작은 변경하지 않았다.
