# FIX11 — 아이소메트릭 우측 차선 좌표 수정

## 원인
FIX9/FIX10은 차량 차선 오프셋을 화면 공간에서 진행 벡터의 직각 법선으로 계산했다.
아이소메트릭 투영에서는 타일 평면의 직각 방향이 화면에서 직각으로 보존되지 않으므로,
방향에 따라 차량이 중앙선에 붙거나 도로 가장자리에 과하게 붙는 왜곡이 생겼다.

## 수정
- 우측 차선 위치를 화면 픽셀 법선이 아니라 타일 좌표계에서 계산.
- DIRS가 +tx, +ty, -tx, -ty 순서이므로 진행방향의 오른쪽을 `(dir + 1) % 4`로 선택.
- 도로 중심에서 오른쪽으로 0.22타일 이동한 점을 아이소메트릭 월드 좌표로 투영.
- 코너 차선 전환 시작을 세그먼트 72% → 82%로 늦춰 직선 구간에서 차선이 흔들리지 않게 함.
- 스폰/교통/시간 로직은 변경하지 않음.
