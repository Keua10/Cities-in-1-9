# 도시 도트 제작 규격

2026-09-12. 사용자가 요청한 방향은 테오타운처럼 용도가 읽히는 도트 그래픽과 깊이 있는 도시 시뮬레이션이다. 이 문서는 현재 구현의 제작 기준이며 최종 미술 완성 선언이 아니다.

## 실제 게임이 읽는 원본

- `src/render/pixelArt.ts`: 40색 팔레트, 정수 래스터, 공통 부품.
- `src/render/buildingArt.ts`: 주거·상업·공업 × 3등급 × 4외형 = 36종.
- `src/render/facilityArt.ts`: 현행 시설 ID 0~25, 총 26종.
- `buildingAtlas.ts`, `facilityAtlas.ts`: 이 원본을 Canvas에 굽고 최근접 필터 텍스처로 올린다.
- `structureMesh.ts`, `structureLayer.ts`: 두 아틀라스를 확대 없이 합치고 건물·시설을 같은 깊이 순서로 그린다. 청크 경계 부지는 앞쪽 모서리가 속한 청크에 한 번만 포함한다.

`public/sprites/buildings.png`, `public/sprites/facilities.png`와 `tools/buildFacilityAtlas.mjs`는 이전 제작 경로의 보관 자료다. 현재 게임의 건물·시설 원본을 바꾸려면 위 TypeScript 제작 파일을 수정한다. `npm run art:facilities`는 과거 7종 PNG를 재생성하므로 현재 아트를 수정하는 명령이 아니다.

## 픽셀·투영·명암

- 한 타일은 64×32. 두 지면 축은 각각 32×16으로 투영한다.
- 셀은 부지에 따라 64/128/192/320/448px. 큰 시설은 같은 크기의 모듈을 더 배치한다.
- 기본 층 간격 8px, 창문 높이 3px. 문·나무·차량·지붕 설비는 셀 크기에 따라 확대하지 않는다.
- 팔레트 밖 색상, 반투명 윤곽, 안티앨리어싱을 사용하지 않는다. 알파는 0 또는 255이고 셀 외곽 1px은 투명하다.
- 지붕·밝은 벽·어두운 벽의 구분과 외곽선 색을 공통 부품에서 정한다. 질감은 지붕 이음선·창문·하역문 같은 의미 있는 구조로 넣는다.
- 확대/축소는 표시 단계의 최근접 필터로 처리한다. 제작 원본의 픽셀 규격은 바꾸지 않는다. 50% 축소에서는 작은 세부가 줄어들므로 큰 실루엣도 필요하다.

## 용도별 식별 요소

| 용도 | 형태와 부품 |
| --- | --- |
| 주거 | 경사지붕, 정원, 발코니, 중정, 테라스 |
| 상업 | 차양, 유리 쇼윈도, 아케이드, 유리 업무동, 아트리움 |
| 공업 | 톱니지붕, 롤러 하역문, 저장탱크, 적재 구역 |
| 소방서 | 붉은 차고, 훈련탑, 여러 소방차 |
| 경찰서 | 청색 건물, 방패 표식, 순찰차 |
| 병원 | 밝은 병동, 십자 표식, 연결 날개, 구급차 |
| 학교 | 교사와 운동장, 국기 |
| 항구 | 수면·부두, 크레인, 컨테이너 또는 여객 건물 |
| 공항 | 터미널, 관제탑, 탑승구와 주기장 |

그림의 차량·배·항공기는 장식이다. 실제 이동체·정박·운항 기능은 별도 시뮬레이션이 담당한다. 항구 그림 속 수면은 시설 부지 장식이며 지형의 항행 가능 수역을 바꾸지 않는다. 건물의 외형 이름은 독립 경제 업종을 뜻하지 않는다.

## 검수

1. `node tools/check/run.mjs pixel visual structure`: 62종 결정론·서로 다른 그림·팔레트·알파·경계·고정 크기 부품, 깊이·UV·캐시, 경계 시설 선택/철거.
2. 개발 서버 `/tools/check/artVisual.html`: 모든 건물을 50/100/200%로 비교. 실제 게임 `/`에서 밀집 배치와 부지 경계를 확인한다.
3. `.check/buildings-pixel.png`, `.check/facilities-pixel.png`는 자동 검사에서 내보내는 현재 원본 미리보기다.
4. 새 시설 추가 시 `MAX_FOOTPRINT`, 시설 종류/규격, 아틀라스 좌표, 찾기 목록, 전체 부지 선택/철거를 함께 확인한다.

남은 비주얼 작업: 도로·지형 팔레트와 질감 조율, 확대 단계별 가독성, 이동 차량·신호등의 건물 가림, 도시 야경·상태별 표현. 현재 모든 가림 문제나 최종 미술 품질이 완료된 것은 아니다.
