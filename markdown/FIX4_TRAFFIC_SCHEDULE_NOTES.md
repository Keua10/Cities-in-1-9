# STEP 3.2 FIX4 — daytime/출퇴근 생활 스케줄 수정

## 시간축
- daytime: 실제 600초 = 1일
- gametime: 실제 60초 = 1일 (기존 유지)
- 최소공배수/정렬점: 실제 600초
- 실제 10분 = daytime 1일 = gametime 10일
- daytime은 Date.now() 기반이라 탭을 닫아도 위상이 계속 흐른다.
- 밤낮(일출/일몰)은 환경 표현만 담당한다. 출근 시각을 늦추지 않는다.

## 출퇴근
- 생활 스케줄 해상도: 15분
- 시민별 고정 출근 시각: 08:30 또는 09:00
- 대응 퇴근 시각: 17:30 또는 18:00
- 출발 시각 = 출근 시각 - 예상 통근시간 - 10분 버퍼
- 통근 가능 거리: L1 28 / L2 36 / L3 44 타일
- 차량 기본 속도: 8.0 타일/초
- 최대 44타일도 무정체 약 5.5초이므로 daytime 약 13분에 해당한다.

## 평일/주말
- accelerated daytime 자체에 월~일 요일을 둔다.
- 평일은 정상 출근.
- 토/일은 일부 상업/공업 인원만 교대 출근한다.
- 주말 화물 통행도 감소한다.
- HUD에 daytime 요일을 표시한다.

## 퇴근 후 상업지대
- 평일 일부 시민은 퇴근 직후 집으로 가지 않고 배정된 상업 건물로 이동한다.
- 금요일은 비율이 더 높다.
- 상업 건물은 현재 세부 업종이 없으므로 술집/식당/여가 상권을 통합 대리한다.
- 45~90 daytime분 머문 뒤 귀가한다.

## 장보기
- 생필품이 완전히 0이 될 때까지 기다리지 않고 72 이하부터 장보기 후보가 된다.
- 평일 취업자는 저녁, 미취업자는 낮 시간대, 주말은 낮~저녁에 분산한다.
- 특정 성별/가족관계 객체는 만들지 않는다. 현재 시민 슬롯 구조 안에서 가구 생활 통행을 표현한다.
