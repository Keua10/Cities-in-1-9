# 대도시 도로 연결 수정 1차

## 문제
기존 생성 도시 후처리는 한 칸 주변만 보고 2차선 도로 여부를 판정했다. 복잡한 교차로, 굽은 간선, 밀집 지역에서는 평행 차선과 실제 교차로를 구분하지 못해 일부 구간이 사다리처럼 전부 연결됐다.

## 변경
- 생성 도로는 기존과 동일하게 명시적 연결값 0에서 시작한다.
- 2칸 폭 도로 판정을 한 칸 인접 여부가 아니라 최대 4칸의 연속된 2열/2행 구조로 판정한다.
- 두 차선이 최소 3행/3열 이상 함께 이어지면 평행 차선으로 보고 횡방향 연결을 차단한다.
- 다른 방향 도로가 바깥에서 최소 2칸 연속 진입하는 경우에만 교차/T자/코너로 인정해 횡연결한다.
- 각 차선의 진행 방향 연결은 유지한다.
- 모든 실제 연결은 기존 canConnectRoads() 검사를 통과해야 하므로 경사 규칙을 우회하지 않는다.
