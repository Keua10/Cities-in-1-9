# STEP 4.8 — L3 인프라 민감도 강화

기준: main `c8661f8`. 기존 공원 요구량과 필수 서비스 계층 배율을 유지하면서 전력·급수·하수 부족에도 계층 차이를 적용했다.

| 건물 계층 | 전력·급수·하수 부족 감점 배율 |
| --- | ---: |
| L1 | 0.6 |
| L2 | 1.0 |
| L3 | 2.8 |

- `src/sim/config/infrastructure.ts`에서 배율과 공통 계산을 관리하며 `MacroSim.evaluate`의 실제 만족도 계산에 연결했다. 기본 부족 감점은 급수 0.18, 하수 0.12, 전력 0.30이다.
- 기존 인구 유예 및 수도·전력 도입 후 시간 유예는 유지했다. 오염수를 마시는 데 따른 0.20 건강 감점은 계층 배율로 할인하지 않는다.
- 기존 서비스·공원·위생 등을 포함한 필요 서비스 총 감점 상한 0.5와 입주 기준선 L1 0.25 / L2 0.45 / L3 0.62를 유지한다. 배율은 상한 적용 전 부족분에 적용되므로 최종 감점이 항상 같은 비율로 커지는 것은 아니다.
- 인프라가 충분하면 추가 감점이 없다. 부족하면 L3 입주율이 더 크게 줄고, 공급 복구 후 다음 평가에서 회복된다. 수요에는 기존 입주율·성장 압력 경로로 이어지며 별도 강제 수요 잠금은 추가하지 않았다.
- 상태판에 L3 건물이 공원·전기·수도 부족에 특히 민감하다는 설명을 추가했다.

기능 검사는 통근·세율 등 다른 조건을 동일하게 두고, 충분한 공원 보너스가 있어도 전력 완전 단절 또는 전력·상하수도 동시 단절 시 L3의 입주 가능치가 0으로 내려가는지 확인했다. 같은 복합 단절에서 L1은 50% 이상의 입주 가능치를 유지한다. 공급이 충분하면 각 계층이 다시 입주 가능치 100%로 돌아가며, 도입 유예도 작동한다. 이는 계산 경로의 짧은 확인이며 도시 전체의 장기 균형 검증은 아니다.

검사: `node tools/check/run.mjs infrastructure`. 최종 프로덕션 빌드도 확인했다. 전체 회귀·장기 밸런스·브라우저 반복 검사는 수행하지 않았다.
