# STEP 4 전체 구현 인계

요청된 STEP 4.1~4.8의 구현 범위를 마쳤다. 이번 작업은 4.6 완료본 `c8661f8`에서 4.7·4.8만 추가했으며, 기존 교통·시설 확장을 그대로 유지했다. 이는 도시 게임 전체의 최종 품질 검수 완료를 뜻하지 않는다.

| 단계 | 구현 범위 | 상세 문서 |
| --- | --- | --- |
| 4.1 | 번영도·도시 레벨·해금 | [완료 기록](STEP4_1_COMPLETION.md) |
| 4.2 | 상하수도·별도 관망·수질 | [완료 기록](STEP4_2_COMPLETION.md) |
| 4.3 | 전력망·건물 자동 공유·공급 범위·대도시 기반시설 | [완료 기록](STEP4_3_COMPLETION.md) |
| 4.4·4.5 | 세율·예산 및 소각·화장·공동묘지 | [완료 기록](STEP4_4_5_COMPLETION.md) |
| 4.6 | 특수 시설·공항/항구·교도소·통신탑 및 광역교통 확장 | [시설](STEP4_6_COMPLETION.md), [교통 확장](STEP4_6_TRANSPORT_EXPANSION.md) |
| 4.7 | 새 외곽 지형 60/30/10 비율·기존 땅 보존 | [완료 기록](STEP4_7_COMPLETION.md) |
| 4.8 | 고소득 건물의 전력·상하수도 부족 민감도 | [완료 기록](STEP4_8_COMPLETION.md) |

이전 문서의 수치는 그 단계 당시의 기록이다. 배관 범위 등 후속 단계에서 변경한 내용은 더 최근 문서를 우선한다. 4.6은 기존 완료본을 인수했으며 이번 작업에서 재구현하거나 전체 재검증하지 않았다.

이번 검증은 `infrastructure` 기능 검사와 프로덕션 빌드로 제한했다. 외곽 비율, 기본 지형 보존, 기존 개척지 보존, 오버레이, 계층별 부족·복구와 유예를 확인했다. Claude가 진행할 전체 회귀·장기 밸런스·실제 서버 저장·시각 검수는 남아 있다.

후속 시각 개선, 건물 종류 다양화, 도시 게임 완성도 확장 및 전쟁/군사 시스템은 이번 범위에 포함하지 않았고 시작하지 않았다. 다음 새 채팅은 현재 main과 이 문서를 기준으로 이어가면 된다.
