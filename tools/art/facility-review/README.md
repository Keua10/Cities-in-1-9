# 특수시설 26종 제작 기록

사용자의 "특수 건물도 다 만들어" 요청으로 기존 코드 그림 26종을 새 도트 스프라이트로 교체했다. 승인된 주거·상업·공업 건물과 어울리는 색감·질감, 기능을 구분하는 실루엣, 2:1 부지 규격이 기준이다.

- 도구: 내장 `image_gen`, 시설마다 별도 호출. 각 `<id>.json`에 실제 프롬프트와 생성 파일명을 기록했다. `specs.json`의 kind/span/name은 기존 게임 시설 ID와 부지 크기에 대응한다.
- 실제 생성 출력은 각각 1254×1254였으며 처음부터 네이티브 크기로 생성된 것은 아니다. 알파가 있는 출력은 알파를 유지했고, 나머지는 그림 바깥과 연결된 회색 체크 매트를 분리했다. 경찰서와 중·대형 항구의 어두운 매트는 따로 측정한 임계값을 사용했다.
- 게임 제작 입력은 `tools/art/facility-sources/`의 네이티브 PNG 26개다. 원본 전체를 최근접 샘플링하며, 바닥 꼭짓점을 중앙에 옮길 여유가 부족하면 전체를 함께 줄인다. 나무·안테나·크레인·탱크를 셀 경계로 잘라서 맞추지 않는다. 재현 가능한 아틀라스 빌드에는 외부 생성 이미지 경로가 필요하지 않다.
- 색상은 승인된 `public/sprites/aligned/`의 `commercial-l3-a`, `residential-l3-a`, `industrial-l3-a` RGB 합집합 안에서 선택했다. 신규 색을 추가하지 않지만, 이 조건만으로 모든 재질의 지각적 색감이 완전히 같다는 뜻은 아니다.
- `facilityFootprint.mjs`는 공통 2:1 투영 후 작은 전면 틈만 해당 열의 바닥 픽셀로 연결한다. 범위는 최대 max(6px, 셀 크기의 3%)다. 수변의 더 큰 빈 공간으로 이어지는 합성 테두리는 제거한다. 원본에서 샘플링된 소품 픽셀은 이 과정에서 삭제하지 않는다. 좌표 변환은 픽셀 행과 높이 비율을 바꾸는 2D 재표본화이며 3D 재구성이나 무손실 복사가 아니다.
- 최종 64/128/192/320/448px 파일: `public/sprites/facilities-detailed/`. 게임 아틀라스: `public/sprites/facilities-v2.png` (2304×1152). `previous/`는 비교용 기존 코드 그림이며 게임은 새 아틀라스를 읽는다.
- 게임 지도와 건설 메뉴는 같은 아틀라스를 사용한다. 이미지 로딩 실패 시 기존 코드 그림을 사용하며 로더의 `placeholder`가 이를 표시한다. 기존 시설 ID, 부지 크기, 비용, 해금 조건, 공급·서비스·교통 시뮬레이션은 바꾸지 않았다. 항구의 선박과 공항 내부의 비행기·짧은 활주로는 그림의 정적 요소다. 실제 항공기·선박 운행과 외부 유도로/활주로 연결 조건은 기존 시스템이 담당한다.

## 참고

TheoTown 커뮤니티의 [소방서](https://forum.theotown.com/viewtopic.php?style=26&t=9307), [종합병원](https://forum.theotown.com/viewtopic.php?t=4477), [소방서 플러그인 시각 사례](https://forum.theotown.com/plugins/list?mode=user&user_id=94991)를 참고했다. 해당 게임 이미지 파일을 프로젝트 에셋으로 복사하지 않았다. 스타일 이미지 입력은 이 프로젝트의 승인 건물 3종을 사용했다.

## 검수 및 재생성

`npm run art:facilities`로 저장된 네이티브 입력에서 동일한 최종 파일과 아틀라스를 재생성한다. `node tools/check/run.mjs facilityDetails`로 26개 ID·부지 크기, 해상도, 알파 0/255, 투명 테두리, 중심/전면 경계, 공통 팔레트, 원본 좌표의 캔버스 이탈 부재, 아틀라스 셀 RGBA 일치, 메뉴/게임 일치, 실패 시 대체 로딩을 검사한다.

`tools/check/facilityDetailsVisual.html`에서 기존/신규, 주변 건물, 연속 배치, 부지 경계, 정수 배율을 비교한다. `facilityDetailsScene.html`은 실제 WorldRenderer 검수 장면이며 기존 저장 도시에 영향을 주지 않는다. 높이가 서로 다른 타일을 가로지르는 부지의 자동 평탄화 시스템을 추가한 것은 아니다.
